# EMATH 100 — Make-Up Quiz (synthetic fixture)

This is a synthetic exam used only to validate the grading skill. It contains
no real student data.

Instructions: submit one report file and one workbook containing your
iteration values for each method below. Show all iterations. An optional
5-point video demo exists but is excluded from this grading run.

## Question 1 (10 points)

Find the root of f(x) = x^3 - x - 2 on the interval [1, 2].

(a) Use Bisection with tolerance 0.05 on the bracket width.
(b) Use Newton-Raphson starting from x0 = 1.5.

Report the iteration values and the final root for each method.

## Question 2 (10 points)

Find the root of g(x) = x^3 - 2x - 5.

(a) Use the Secant method with x0 = 2 and x1 = 3.
(b) Use False Position on [2, 3] for three iterations.

Report the iteration values and the final root for each method.
