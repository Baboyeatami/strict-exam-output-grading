# EMATH 100 — Make-Up Quiz Rubric (synthetic fixture, raw instructor format)

This is the instructor's rubric exactly as an instructor might hand it over —
not in the skill's canonical profile format. The skill must derive the
canonical profile from this file during intake.

Total: 20 points for the written file outputs, plus an optional 5-point video
demonstration that is excluded when grading file outputs only.

## Question 1 — root of f(x) = x^3 - x - 2 on [1, 2] (10 points)

- (a) Bisection with tolerance 0.05 on the bracket width: iteration values and
  final root — 5 points
- (b) Newton-Raphson from x0 = 1.5: iteration values and final root — 5 points

## Question 2 — root of g(x) = x^3 - 2x - 5 (10 points)

- (a) Secant with x0 = 2, x1 = 3: iteration values and final root — 5 points
- (b) False Position on [2, 3] for three iterations: values and final root —
  5 points

## Evidence standard

Iteration values must appear in a submitted workbook sheet or report table.
Prose claims without values earn no points. Full credit for a method requires
a final root within 0.01 of the true root (Q1 approximately 1.5214;
Q2 approximately 2.0946).

## Exclusions

The 5-point video demonstration is not graded for this run. Exclude it from
the maximum (the written denominator stays 20); never score it as zero.
